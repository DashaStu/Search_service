# Simple Text Search Service

Сервис для полнотекстового поиска по документам, реализованный с использованием FastAPI, PostgreSQL и Elasticsearch.

## Технологический стек
* **Framework**: FastAPI (Async)
* **Database**: PostgreSQL
* **Search Engine**: Elasticsearch
* **Containerization**: Docker Compose

## Архитектура
1. **PostgreSQL** — основной источник данных (хранит полные объекты документов).
2. **Elasticsearch** — поисковый индекс (хранит только текст для быстрого поиска).
3. **Синхронизация**: При импорте данные записываются в обе системы параллельно. При поиске мы находим `id` в Elasticsearch и запрашиваем полные данные из PostgreSQL.

## Запуск
Для запуска всех сервисов (PostgreSQL, Elasticsearch, API) выполните:

```bash
docker-compose up --build
```

Сервис будет доступен по адресу: http://localhost:8085
## API Документация
Интерактивная документация (Swagger UI) доступна по адресу:
```
http://localhost:8085/docs
```
## Основные методы
* GET /search?query={text} — поиск документов по текстовому запросу. Возвращает первые 20 результатов, отсортированных по дате.
* DELETE /documents/{id} — удаление документа из базы данных и поискового индекса.
## Загрузка данных
Данные загружаются автоматически при старте сервиса из файла data/posts.csv, если база данных пуста.
## Технические примечания
* Асинхронность: Весь проект реализован с использованием async/await (asyncpg, sqlalchemy-asyncio, elasticsearch-async).
* Консистентность: В текущей реализации удаление происходит последовательно. Для Production-систем рекомендуется внедрение очереди сообщений (RabbitMQ/Kafka) для обеспечения Eventual Consistency.
* Тестирование: Запуск тестов выполняется командой:

```bash
docker-compose run tests
```
